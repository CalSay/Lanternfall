# cache-auto-setting: a settings home for "Open the next ones automatically"

Status: proposed. Source: cache-core scope cut.

Cache-core puts the auto-open switch on the cache card (from the 3rd cache). Once the player stops seeing big cache cards, there is no place to change it. Add the switch to the Journal or settings page (`cacheSetAuto` and `cacheAuto` in `55-caches.js` are the API).
