# Lanternfall game bible: entry point

This guide routes Codex to existing sources; it does not replace [GAME.md](GAME.md) or
[DECISIONS.md](DECISIONS.md). Baseline: 2 October 2026, accumulation commit `387fe2d`.

Lanternfall follows one hero carrying the lamp along the Lantern Road. Combat is active; gathering, gatherer
shifts and camp construction progress away. Permanent progress, single-player depth and light in the dark are
standing pillars. Wren, Tobin and Pip are playable; 32 complete heroes and five regions are the Season 1 goal.
Never treat that goal as implemented content. Monetisation remains undecided.
