# New-style engine: the data contract for wire cards

Card `ns-scenery-engine` (plan.md 8.1, with the plan's sections 2, 4.2, 4.3 and 5.3). The engine draws layered painted
scenery and sprite foes, nodes, beasts, props and camp stations at actor scale. It does this only when a screen has every
piece in. No art ships with it: `NS_ART` does not exist yet, so every screen draws classic. Each wire card adds its pack's
entries to `src/js/21zc-data-nsart.js` (generated by its embed tool, never by hand) and wires the hero art it needs. The
screen then turns new on its own.

Files:

- `src/js/59n-ns-screens.js` (core): the pieces each screen draws, and the zones whose packs carry each piece.
- `src/js/64m-new-style.js` (browser): decoding, frames, drawing, and the whole-screen rule.
- Hooks: `62-stage.js` (scenery layers, foe slots), `63c` (nodes, beasts, piles), `63d` (grove props, camp panorama),
  `64-looks.js` (critters), `75-turn-ui.js` (the foe portrait) and `62b-fx.js` (aim point).
- Packs: `tools/build.mjs` (`AREA_ART` kind `ns`, `nsPacks`), `75-art-load.js` (`artNsWant`, put) and `src/boot-loader.html`.
- Checks: "new-style screens (ns-scenery-engine)" and "new-style screens (browser)" in `tools/check.mjs`, with the test
  fixture `tools/lib/ns-fixture.mjs`. The fixture's flat marker colours are not art and never ship.

## Pieces

A piece is `group:key`. Its entry is `NS_ART[group][key]`, and its pack id is `ns:<group>.<key>`. Keys use `a-z 0-9 _ . -`.

| Group | Key | Shown on |
|---|---|---|
| `scenery` | `fight.<area>` (`zoneAreaIdx`, 0 = zones 1-5), `gather.<set>` (`gmine`, `gglade`, `gwoods`, `gmeadow`), `camp` | that screen |
| `foe` | `nsFoeKey(m)`: the monster's type key (`imp`, `gloomjaw`; a zone monster's `skin`), `<type>.elder` (the zone boss), `<monster>.captain` (a zone Captain), the Champion's `key` (`regent`, `cantor`), `fenmother`, `silas` | turn fights |
| `node` | `<kind>.<tier>` (`wood.1`, `ore.2`) | gathering |
| `beast` | `HUNT_BEASTS[t-1].key` | hunting (on the woods scenery) |
| `prop` | `pile.<cart, crate, logs, basket>`, `fire`, `stake` (an unbuilt plot), `tent`, `pack` | gathering, grove, camp |
| `npc` | `hesketh` | the cold Hearth grove |
| `station` | the `CAMP_B` id | grove plots, camp |
| `gatherer` | the gatherer's `key` (else its id) | camp |
| `critter` | the `CRITTER_ART` id | every screen where it is worn |
| `hero` | the hero id, through `nsHeroArt` (below) | fights and gathering |

`nsFightPieces(z)` is a zone's scenery plus every foe its turn fights put on the stage. The check plays 41 spawns in each
zone from 1 to 35, with zone monsters off and on, and finds the two lists equal. `nsGatherPieces(kind, t, grove)` and
`nsCampPieces(view)` do the same for gathering and camp. A wire card that adds a foe to a fight adds it to `nsZoneFoes`
too, and that check holds it to it.

## An entry

```js
NS_ART = { v: 1,
  scenery: { 'fight.0': { w, h, gy, safe: [x0, x1], layers: [{ img, par, fore, tile }], lights: [[x, y, r, 'r,g,b', a]], img: {...} } },
  foe: { imp: { f: { idle: [x, y, w, h, ax, ay, atlas?], ... }, head, hit: [dx, dy], strike: [dx, dy], hover, lights: [[dx, dy, size, 'r,g,b']], img: { sheet: '<b91>' } } },
  node: { 'wood.1': { f, contact: { wren: [dx, dy], ... }, chips: [dx, dy], glint: [dx, dy], img } },
  prop: { fire: { f: { cold, lit0, lit1 }, fps: 6, img } } }
```

- `img` maps picture names to base91 PNG or WebP bytes. Byte rule: lossless WebP, at most 64 colours, 1-bit alpha. The
  page keeps every entry with `img: {}`, and the entry's pack carries its pictures. A piece with no pictures is "not loaded".
- `f[name]` gives a frame's box on its atlas (the first picture unless index 6 names one) and its anchor `ax, ay`: the feet
  point for actors, the base line for nodes and props.
- Every offset (`head`, `hit`, `strike`, `contact`, `chips`, `glint`, `lights`, `hover`) is in art px from the anchor, with
  y negative upward.
- Sprites draw at **0.5 actor px per art px**, as route S Wren does, so a foe matches her scale at every view. They are drawn
  on whole device px, nearest-neighbour at 1x or more, and as a cached smoothed downscale below that.
- Scenery is in its own picture px. It is scaled to cover the stage, with the seat line `gy` on the stage ground line (GY)
  and centred on `safe`. Each layer is offset by `par` times the camera sway. `fore` layers draw over the actors. `tile`
  repeats a layer across the stage. `lights` use the game's glow.

### Frame names

| Group | Frames (missing ones fall back to `idle`) |
|---|---|
| foe | `idle` (held; the code breathes it), `advance`, `wind1`/`strike1`, `wind2`/`strike2` (or `wind`/`strike`), `hurt`, `defeat` |
| beast | `idle`, `windup`, `hurt`, `fallen` |
| node | `idle`, `spent` |
| prop | pile `p<n>` (the pile's fill step; the nearest lower step draws), fire `cold` and `lit` or `lit0..N` at `fps` |
| station | `lv<n>` (the nearest lower level, then `idle`) |
| npc | `idle`, `lit` |
| gatherer | `idle`, `rest` |
| critter | `idle0`, `idle1`, `hop0`, `hop1` |

A name with a number falls back to the nearest lower number. A name `x` with `x0..xN` frames plays at `fps` (8 by default)
and holds `x0` under reduced motion.

## The whole-screen rule (plan 4.2)

`nsScreen()` decides when the screen opens: on a fight's zone, a gather spot, or the grove. Every piece must be wired,
loaded and decoded, including `hero:<id>` and a worn critter.

- **on**: the screen draws new style.
- **wait**: everything is loaded but still decoding. The stage shows the backdrop alone, for at most 1.5 s.
- **off**: the screen draws classic for the whole visit. If a piece is wired but not loaded, it asks the loader for it, so
  the next visit opens new.

Some screens stay classic: real-time fights, the Deepwell, Provings, the raid and the Trophy Wall. Classic art (Settings >
Hero art) turns every screen classic, and the split build then fetches no `ns` pack.

The first turn fight asks for the cold Hearth's woods and the save's gather spot. The boot set carries the save's zone's
fight pieces and the critters. New-style packs never hold the game (`n` in the pack table), and Classic art leaves them
out (`x`).

`nsHeroArt[mode][hero]` returns `true` (in), `'wait'` (decoding) or `false`.

- `fight.wren` is route S (`wrenSOn`).
- There is no `gather` entry yet, so gathering stays classic until `route-s-wren-gather` adds one. Each hero's route S card
  adds its own entries.

## For the wire cards

- **Zone monsters.** A1's foe kits (`59l`) take their move timings from today's `FOE_ART`. The A1 wire card should check
  them against the new 8-frame sheets.
- **Captains.** A Captain is its own `foe` entry (`imp.captain`). The plan has Captains as recolours, but the engine has no
  palette recolour (bytes): if A1 wants one, add it in `64m` `art()` and put it under `foe.<type>.captain.pal`.
- **Allies.** They are not on the stage, so they are not pieces. When they arrive there, add them to `nsFightPieces`.
- **Camp.** The panorama (`63d` `paintNs`) places tents at (35 + 41i, 103), stations at (`b.x`, 120) with the label at y 135,
  the fire at (`homeX`, 142), and gatherers at their `x, y`. The camp wire card owns those numbers and the Trophy Wall.
- **Nodes.** A node's `contact[hero]` x sets where that hero stands to strike it. That hero's tool tip on its impact frame
  must meet the notch.
- **Page size.** `tools/lib/page-size.mjs` measures every piece against its kind's ceiling (plan 5.1).
  - Scenery: 400 KB.
  - Node: 70 KB.
  - Station, gatherer, critter, NPC or prop: 25 KB.
  - A foe takes its entry's `kind` (`monster` by default, `champion`, `elder`). A `monster` also needs a `zone` for its
    area's sheet.
  - The area sheet counts a new-style monster beside the classic one for now. A1's wire card splits them when it wires
    the Imp.
- **Bytes.** This card's code costs about 0.006 MB of boot set. A zone 1 boot is 3.4994 MB, 0.0006 MB under the 3.5 MB warn line. The boot set's ns packs (zone 1's fight
  and the critters) are A1's to fit under the load lines; never raise a line.
