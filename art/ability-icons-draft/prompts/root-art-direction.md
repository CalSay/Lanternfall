# Manually authored icon direction

These are concept drafts for review, not approved runtime replacements. Creative compositions in `root-compositions.json` were authored by the coordinator after reading each exact card; the delivery code only inserts these strings into numbered cells and saves the exact prompt. It does not invent art or generate prompt directions.

Use the approved concept as palette/material/equipment reference only. Render isolated ability symbols, never a hero body pose. Match the project’s action icons: small confident dark outlines, broad readable pixel-inspired shapes, warm material highlights, restrained detached motes. Readability at 32 pixels takes priority over ornate miniature illustrations.

Shared Warrior uses iron, brown and brass. Shared Ranger uses wood, ivory, muted green and silver. Shared Mage uses ivory/gold holy, cyan frost and violet source-labelled hex. Signature identity may differ from shared class glyphs, but shared icons imply no unsupported weapon equipment or extra targets.

For hero plates, nine active symbols occupy cells 1–9, three passive emblems occupy cells 10–12. Passive symbols use a settled compact silhouette rather than an explosive trail. No UI frame, border, lettering, numerals, watermark, floor, drop shadow or gradient background. Every cell is centred with generous plain magenta #FF00FF separation; never place magenta inside the actual glyph. The geometry guide constrains layout only and must not appear in the output.

Reviews must inspect actual extracted icons at native 32 and 48 pixels and at 128 pixels, verify each cell against the exact card, and inspect whole-pack collisions. A visually attractive icon cannot claim resurrection, automatic defence, summoned actors, extra hits or equipment throwing. Notes are resolved by evidence-guided targeted edits, then the reviewer examines the revised pixels. Closure is an agent review outcome, not owner art approval.
