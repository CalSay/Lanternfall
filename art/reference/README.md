# Style references (reference only, never shipped)

Images the owner shared as inspiration. Nothing here goes into the game, and no pixels are copied from them.
Some are third-party (PromptBase previews, an artist's listing, the free Tiny RPG packs), so they stay in this
private repo for reference and are never published.

| File | What it is | What we took from it |
|---|---|---|
| hero-coat-proportions.png | A single hero in a long coat | Hero proportions (about 3.5-4 heads), loose outline, muted palette |
| chunky-heroes-1.webp, chunky-heroes-2.webp | PromptBase preview sheets of chunky fantasy heroes | The chunky, jewel-toned hero style, one glow focal point per hero |
| item-icons.png | PromptBase item icons | Icon style: rim light, one glow colour, sparkle specks (for Sigils, gems, uniques) |
| region-scenes.png | PromptBase scene thumbnails | Night scenes lit by saturated glows; region mood mapping (see wave log) |
| tiny-rpg-packs-contact-sheet.png | Our contact sheet of the free Tiny RPG Character packs (Soldier, Orc, Demon, Blood Monster) | The animation set (idle, walk, attacks with swoosh arcs, hurt, death) and enemy ideas |
| artist-commission-pricing.jpg, artist-sample-*.jpg/.gif | An artist's listing and samples (about £86 per character) | Pricing benchmark for a future real artist; animation references |
